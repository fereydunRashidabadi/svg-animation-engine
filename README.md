# SVG animation engine

Reusable source library for deterministic SVG animation, story timelines, camera,
audio and browser MP4 export. No character artwork, profiles, personalities,
stories, recordings or branded application are included.

Read [ENGINE_GUIDE.md](ENGINE_GUIDE.md), then [API.md](API.md).
With Node >=22 run npm test, or node --test tests/engine-public.test.mjs.
No dependency installation is required.

This is an engine source distribution. Build your own SVG rigs, story data,
browser interface and content pipeline. Codec licenses are in vendor/mediabunny.
The default-deny .gitignore protects local creative material. Deliberately allow
new public paths before committing them.
