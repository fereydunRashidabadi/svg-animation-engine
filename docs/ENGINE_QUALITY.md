# Animation release checklist

Read API.md before authoring. Discuss new motion capabilities before implementation.

- Establish intent, anticipation, readable action, consequence and reaction.
- Keep one clear visual focus; check silhouette, expression and hands.
- Preserve geography, facing, gaze, ground contact and prop support.
- Review camera start/midpoint/end and intentional framing.
- Use one deterministic clock for motion, camera, mouth, audio and export.
- Use supplied recordings/measured durations; review speech ordering and mix.
- Check neutral endpoints, mirroring, pause/restart/seeks and playback speed.
- Run relevant tests; visual/listening review remains necessary.
- Inspect actual encoded files for export changes.
- Update API.md and explicitly regenerate affected final exports.
